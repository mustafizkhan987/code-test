This repository contains two Java programs designed to demonstrate essential concepts in exception handling and object-oriented programming. The first file, DivideNumbers.java, focuses on safe division using Java’s try–catch mechanism. It accepts two numbers from the user through the Scanner class, performs division, and handles potential ArithmeticException errors, such as when a user attempts to divide by zero. By capturing the exception and displaying a meaningful message, the program ensures that the application does not crash and continues to run smoothly.

The second file, Main.java, showcases the concept of inheritance and method overriding in Java. It includes a parent class named Product, which contains a constructor that initializes a product ID and provides a showDetails() method. The child class, Electronics, extends Product by adding a warranty field and overriding the showDetails() method to display more specific information. The program demonstrates the use of the super() keyword to invoke the parent class constructor and super.showDetails() to reuse parent behavior inside the overridden method. When executed, the program creates an Electronics object and prints its details, illustrating how subclassing enhances and customizes parent class functionality.

Together, these programs serve as clear, beginner-friendly examples for understanding Java exception handling, constructor chaining, inheritance, and method overriding. They are ideal for students learning core Java fundamentals and can be expanded further for academic or project purposes.
